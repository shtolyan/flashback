## Автоматические проверки

- `npm run typecheck`: сервер, общие контракты и клиент проходят проверку типов.
- `npm test`: 9 сценариев — старый HTTP-контракт и неизменённый Python-клиент HexLive, конкурентные записи с expectedRevision, комментарии, переходы статусов, пагинация, патчи, события после фиксации транзакции, атомарность и повторный импорт.
- `npm run test:ui`: 5 сценариев Chromium — пагинация и восстановление прокрутки при назад/вперёд; создание, изменение, комментарий, подтверждение, архив и удаление; обновления между вкладками и сохранение черновика при конфликте; мобильная ширина 390 px; повторная загрузка оболочки PWA без сети и обновление данных после подключения.
- `npm run build:web`: статический экспорт Expo. Основной JavaScript-файл около 1,3 МБ без сжатия.
- `npx expo export --platform ios --platform android --output-dir dist-native`: экспорт обеих платформ с Hermes выполнен.

Docker-образ собран на Node.js 24 Alpine и запущен через Compose. Проверены HTTP health, выдача всех 344 отчётов и обслуживание веб-сборки. API и PostgreSQL оставлены работающими с `restart: unless-stopped`.

## Границы первой версии

Один серверный процесс, отдельный PostgreSQL и единая кодовая база интерфейса. Авторизации нет по согласованному требованию. Перед несколькими серверными процессами нужен общий транспорт событий. Импорт является разовой копией, а не синхронизацией со старым трекером. PWA сохраняет оболочку; офлайн-очередь записей не реализована.
